# Smart Revision Planner

A Streamlit app that helps students plan revision more effectively based on:
- subjects
- topics
- weakness level
- time left before exam

## Features
- Enter multiple subjects
- Add topics for each subject
- Set weakness levels from 1 to 5
- Get ranked subject priority
- Receive smart revision suggestions and study duration

## How to run locally
```bash
pip install -r requirements.txt
streamlit run app.py
